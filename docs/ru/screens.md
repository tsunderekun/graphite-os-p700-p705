## Общие состояния
- Нажатие: fill surf2, без сдвига.
- Активное: рамка/текст accent.
- Текущая строка: sel + accent-маркер/текст.
- Пусто: одна строка dim по центру.
- Нет MPD: скрыть прогресс/время, показать «MPD недоступен» 12 dim.
