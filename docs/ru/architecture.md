# OS-DEV-HANDOFF — graphite shell (LG P700)

Пакет для разработки ОС: дизайн-система, 12 экранов, план реализации.
Макеты: `shell/*.html`, рендеры `artifacts/shell/*.png`, спецификации:
`DESIGN-SYSTEM.md`, `SCREENS.md`. Всё 480×800, 16 бит, X11 на fbdev.

## 1. Цель
Один шелл на X11 вместо двух режимов: лончер, док, приложения и плеер — один
интерфейс. Плеер переезжает в X, логика (MPD, обложки, очередь, инфо,
настройки, темы, seek, клавиши) сохраняется. Старый fb-плеер остаётся
аварийным режимом.

## 2. Архитектура
- **Один X-сервер** (`X :0 -nolisten tcp vt1`), 16 bpp, `Rotate UD`,
  `xset s off -dpms`; панораматор `fbpan-ng` 10 Гц после готовности X
  (ядро #23 с патчами `msm_fb`; проверено 300 с + стресс).
- **Шелл** — Xlib-приложение (без GTK/Qt):
  - фон-окно 480×800 для лончера/плеера/лока/диалогов;
  - шапка приложения 40 px и док 48 px — отдельные override-redirect окна
    поверх контента;
  - контент приложений — окно 480×712 в (0,40).
- **Плеер** — часть шелла (общие токены/док/лок): переносим рендер из
  `notes/lp7player.cpp` (`Canvas` → `XPutImage`), логику оставляем.
- **Внешние приложения**: `st`/`xterm` (терминал), `pcmanfm` (файлы),
  `dillo`/`netsurf` (браузер) — запускаются в окне 480×712; шапка/док
  остаются шелловыми. Назад/закрыть — кнопки шапки; Home (железо) — лончер,
  приложение скрывается (unmap).
- **Заметки** — встроенный редактор (текст + клавиатура RU/EN), чтобы
  контролировать клавиатуру и сохранение.
- **Тач/клавиши** — evdev напрямую (`event0`, `event1`, `event5`), как в
  плеере; X-input для внешних приложений продолжает работать (несколько
  читателей evdev допустимо).
- **Звук** — MPD TCP `127.0.0.1:6600`, `lgjack` для наушников; EQ — позже.

## 3. Окна и фокус
- Шелл: полноэкранное окно (лончер/плеер) + шапка + док (override-redirect).
- Приложение: окно 480×712; шелл позиционирует его через XMoveResizeWindow,
  поднимает шапку/док (XRaiseWindow) и держит их поверх.
- Home: скрыть окно приложения (XUnmapWindow), показать лончер.
- Назад в шапке: закрыть приложение (XDestroyWindow/kill) и вернуть лончер
  или предыдущий экран.
- Фокус: `XSetInputFocus` на окно приложения при запуске; шапка/док — свои
  кнопки, обрабатываются шеллом.

## 4. Загрузка и откат
1. `session-shell`: `fbset16 16`, подсветка, X, ожидание `xdpyinfo`
   (с `timeout 3`), `xset s off -dpms`, `fbpan-ng`, запуск шелла.
2. Если X не готов за 20 с — запустить `session-player` (fb-плеер).
3. `/etc/lgtest-mode`: `shell` (по умолчанию) | `player` (аварийный fb).
   Переключатель режима — в настройках оболочки («ЗАПУСК: ОБОЛОЧКА / БЕЗ X»)
   и та же строка в настройках fb-плеера (чтобы вернуться из отката); пишет
   файл, применяется после перезагрузки, рядом — кнопка «Перезагрузить».
4. Автоматический fallback файл **не меняет**: если выбран `shell`, но X не
   поднялся за 20 с — запускается fb-плеер; предпочтение остаётся `shell`.
5. Watchdog: если шелл упал — перезапуск (не более 3 раз), иначе fb-плеер.

## 5. Клавиши и питание
- Vol± коротко — `setvol ±5`; удержание ≥0.7 с — next/prev.
- Power коротко — лок (подсветка 0, ввод игнорируется); ещё коротко — экран
  блокировки; свайп вверх ≥120 px, разблокировка на отпускании.
- Power ≥1.5 с — диалог «Выключить питание?» → `sync` + `/sbin/poweroff`.
- Home — лончер; в плеере — экран «сейчас играет»/лончер (по контексту).
- Подсветка клавиш: авто (5 с), вкл, выкл; при локе — 0.

## 6. Шторка (status shade)
- Оверлей 480×470 (override-redirect окно поверх шелла), фон bg, нижняя
  линия section, ниже — затемнение 62 %.
- Открытие: свайп сверху вниз на любом экране (evdev: старт y<32, dy>80).
  Закрытие: свайп вверх >80 или тап по затемнению.
- Шапка 40: время, дата, шестерёнка → настройки оболочки.
- 8 быстрых плиток 100×72 (4×2): Wi-Fi, Bluetooth, Звук, Яркость, Клавиши,
  Плеер, Лок, Питание. Активная — accent.
- Слайдеры 448×4: громкость (MPD `setvol`), яркость
  (`/sys/class/leds/lcd-backlight/brightness`).
- Уведомления — карточки 56: MPD (тап → плеер), Wi-Fi; очередь уведомлений
  пополняют Wi-Fi/батарея/MPD.
- Действия: Wi-Fi — `nmcli`/wpa_supplicant; BT — `rfkill`/`btattach`;
  звук — MPD; клавиши — подсветка; лок/питание — штатные обработчики.

## 7. Файлы и сборка
- Исходники макетов: `shell/*.html`, `shell/style.css`, `shell/app.css`,
  шрифты `shell/fonts/` (DejaVu Sans/Bold/Mono с телефона).
- Рендер: `python -m http.server 8765` в `shell/`, Playwright 480×800,
  скриншоты в `artifacts/shell/`.
- Плеер: `notes/lp7player.cpp` (логика/рендер) → X-версия.
- Ядро: pkgrel 22/23, патчи `notes/desktop/kernel/0001,0002`; boot-image
  `artifacts/boot-rot.img`; прошивка p9.
- Сервисы: `/etc/local.d/zz-mode.start` → `session-shell` (или player).

## 8. Ограничения
- 480×800, RGB565; панель перевёрнута (блит/поворот на 180°).
- 1 ГГц, без GPU: без анимаций, без композитинга; перерисовка по событию,
  плеер — раз в секунду. X + шелл + приложение ≈ 40–60 МБ.
- Шрифты только DejaVu (Sans/Bold/Mono); текст ≥11 px (терминал 10).
- Один акцент, прямые углы, линии 1 px, без теней/градиентов/стекла.
- Кнопки ≥44 px; в доке нет назад/домой/питания (железо).

## 10. Риски1. Стабильность X/fbdev на длинной сессии — ядро #23 проверено 300 с,
   нужен 10-минутный прогон.
2. Ввод: шелл и X одновременно читают evdev — не перехватывать события
   приложений (шелл реагирует только на свою шапку/док/жесты).
3. Внешние окна не любят позиционирование без WM — тестировать
   `st`/`pcmanfm`/`dillo` с override-redirect шапкой/доком; при проблемах
   запускать их fullscreen 480×800 и скрывать шапку/док.
4. Память 400 МБ: не держать браузер и файловый менеджер одновременно.
5. Падение шелла — watchdog и откат на fb-плеер.

## 11. «Пуск»: приложения, закрепление, правка (Metro)
- Главный экран — плитки приложений; live-плитка музыки показывает трек и
  play/pause (без анимаций).
- Долгое нажатие (650 мс) на плитке → режим правки: сверху «Плитки» и
  «ГОТОВО», у каждой плитки «×» (убрать), плитка «＋ Добавить» открывает
  список приложений.
- Список приложений (`m-apps`): строки 64 из `.desktop`-файлов
  (`/usr/share/applications`), иконки, имя; справа «＋» (не закреплено) или
  «✓» (закреплено, accent). Тап — запуск; ＋/✓ — pin/unpin.
- Хранение: `~/.config/graphite/start.json`:
  `{ "pinned": [{"id":"lp7player","size":"wide"}, ...] }`; порядок = порядок
  в массиве; размеры 1×1 / 2×1 (2×1 пока только музыка).
- Реестр: id приложения = имя `.desktop` без суффикса; Exec — команда запуска;
  Icon — путь/имя иконки (PNG 48×48 в `/usr/share/icons`); Categories —
  фильтр. Список разрешённых приложений — отдельный JSON, чтобы не тащить
  весь system.
- Поведение: запуск из списка/плитки; Home — назад на «Пуск»; back — в
  приложении; задача в стеке; при нехватке памяти — выгружать старые
  (кроме плеера).
- Визуально: Metro-проход — плитки и кнопки **без рамок**, крупные заголовки
  DejaVu ExtraLight, pivot, app bar. Токены и метрики — `DESIGN-SYSTEM.md`,
  макеты `shell/m-*.html`.
